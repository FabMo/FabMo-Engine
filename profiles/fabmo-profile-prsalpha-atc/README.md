# fabmo-profile-prsalpha-atc
FabMo machine profile for the ShopBot PRSalpha with ATC.

Same base as fabmo-profile-prsalpha (limit-switch roles, 96" x 48"
envelope, PRSalpha steps-per-unit and speeds, standard variables) plus
the ATC macro set and ATC.TYPE 6.

Macros are the universal Desktop set plus the ATC add-ons (see
fabmo-macros-dt-main base/ and max-atc-ADD/); per-machine values are
carried in the profile's standard variables.

Bundled apps: ShopBot-Sb4, Tool Status, SmoothSketch.
