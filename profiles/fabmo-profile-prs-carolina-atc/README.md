# fabmo-profile-prs-carolina-atc
FabMo machine profile for the ShopBot PRS Carolina with ATC.

Same base as fabmo-profile-prs-carolina (limit-switch roles, 96" x 48"
envelope, Carolina steps-per-unit and speeds, standard variables) plus
the ATC macro set and ATC.TYPE 8.

Macros are the universal Desktop set plus the ATC add-ons (see
fabmo-macros-dt-main base/ and max-atc-ADD/); per-machine values are
carried in the profile's standard variables.

Bundled apps: SmoothSketch.
