# fabmo-profile-prs-carolina
FabMo machine profile for the ShopBot PRS Carolina (without ATC).

Built with the Profile Designer app as a diff against the default profile:
limit-switch input roles (inputs 2/3/5), 96" x 48" envelope, Carolina
steps-per-unit and jog/feed speeds, and the standard variables
(prox/Z-zero/MTC) shared with the other PRS/Desktop profiles.

Macros are the universal Desktop set (see fabmo-macros-dt-main); all
tools use the same macros, with per-machine values carried in the
profile's standard variables.

Bundled apps: SmoothSketch.
